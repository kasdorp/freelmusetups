# FreeLMUsetups — Telegram-бот сетапов для Le Mans Ultimate

## Что это
Telegram-бот, который бесплатно выдаёт сетапы (.svm) для игры Le Mans Ultimate.
Пользователь выбирает: **Класс → Машина → Трасса → Автор сетапа → файл**.
Два языка интерфейса: EN / RU (выбор при /start, хранится в data/users.json).

## Ключевые факты об игре (исследовано 2026-07-18)
- Сетапы игры лежат в `C:\Program Files (x86)\Steam\steamapps\common\Le Mans Ultimate\UserData\player\Settings\<Трасса>\*.svm`
- `.svm` — текстовый файл. Машина определяется по строке `//VEH=...\Installed\Vehicles\<ПапкаМашины>\...`
  (100% надёжно), запасной вариант — `VehicleClassSetting="..."`.
- Папки машин игры: `...\Le Mans Ultimate\Installed\Vehicles\` — 36 машин
  (Hypercar, LMP2, LMP3, LMGT3, GTE, Cup). Полная карта — в `catalog.py`.
- Имена файлов сетапов обычно: `<Автор> <версия> <машина> <трасса> <Q/R>.svm`
  (например `HYMO 1.3.3 RCF LM ER.svm`, `Bober 1.3.3_HUR_INT_Q v1.svm`).

## Архитектура
- Python 3.14 (запуск через `py`), aiogram 3.x, long polling (хостинг не нужен, работает с любого ПК).
- Файлы:
  - `bot.py` — точка входа (создание бота, диспетчер, polling)
  - `config.py` — читает `.env` (BOT_TOKEN, ADMIN_IDS, SETUPS_DIR, LIBRARY_CACHE_TTL)
  - `catalog.py` — справочник машин (папка → имя, класс) и трасс (папка → EN/RU имя)
  - `library.py` — сканер библиотеки сетапов с кэшем (TTL 15 c) и авто-определением машины
  - `i18n.py` — все тексты EN/RU, функция `t(lang, key, **kwargs)`
  - `storage.py` — JSON-хранилище: язык пользователей (`data/users.json`), счётчики скачиваний (`data/stats.json`)
  - `keyboards.py` — inline-клавиатуры; в callback_data короткие sha1-хэши (10 симв.), лимит 64 байта не превышается
  - `handlers.py` — все хэндлеры aiogram (Router)
  - `setups/` — библиотека сетапов: `setups/<ПапкаТрассы>/[<Автор>/]файл.svm`
  - `start_bot.bat` — запуск для новичка (создаёт venv, ставит зависимости, запускает)

## Система обновления сетапов (главная фича)
Просто кинуть `.svm` в `setups/<ПапкаТрассы>/` (имя папки — как у игры) —
бот сам определит машину (из содержимого файла) и автора (первое слово имени файла
ИЛИ имя подпапки `setups/<Трасса>/<Автор>/*.svm`). Перечитывание автоматическое
(кэш 15 секунд), перезапуск бота НЕ нужен. Код менять не нужно.
Новые машины/трассы из будущих DLC не ломают бота: неизвестная машина попадает в класс
"Other" с сырым именем папки, неизвестная трасса показывается по имени папки.

## Обновление 2026-07-21
- **Трассы всегда на английском.** `catalog.TRACKS` теперь `dict[str, str]` (без RU-варианта),
  `track_name(folder)` больше не принимает `lang`. Обновлены вызовы в keyboards.py/handlers.py.
- **Система статистики скачиваний переделана** (storage.py). Раньше ключом был точный
  относительный путь к файлу — при каждом апдейте версии сетапа автором (1.3.1 → 1.3.2)
  появлялся новый ключ, счётчики никогда не накапливались для «того же» сетапа, а список
  топ-скачиваний бесконечно раздувался мусором (это и была жалоба «зафулилась»). Теперь ключ —
  `car|track|author` (устойчив к переименованиям версий). При первом запуске старый
  data/stats.json с полем "downloads" мигрируется: total_downloads сохраняется,
  подробная разбивка обнуляется (старые пути нельзя надёжно сопоставить с машиной).
  `storage.record_download(car, track, author)` — новая сигнатура (было: rel_path).
- **Определение Q/R сетапов исправлено** (library.py). Старый код был жёстким списком
  (Q, EQ, CQ, QUALI / R, ER, CR, RACE) и пропускал реальные варианты вида "WQ"/"WR"
  (Wet Quali/Race) — такие файлы не получали эмодзи ⏱/🏁. Заменено на общее правило:
  один необязательный условный символ (C/E/W/...) + Q или R + цифры, как отдельный токен
  на границах слова — ловит любые будущие префиксы без правок кода. Берётся ПОСЛЕДНИЙ
  найденный токен в имени файла (маркер сессии обычно в конце), это защищает от ложных
  срабатываний на трек-коды вроде "QAT"/"BAR"/"HUR", которые проверены и не матчатся.
- Библиотека выросла до 1092 сетапов (пользователь активно пополняет сама).
  Появились новые папки трасс "Algarve" и "COTA", которых нет в catalog.TRACKS —
  падать не должно (fallback на сырое имя папки = уже английское), но для красоты
  стоит когда-нибудь добавить их в словарь.
- **Важный урок**: пользователь держит свой собственный процесс bot.py запущенным
  постоянно через start_bot.bat на этой же машине. Перед тем как самому запускать бота
  в фоне для тестов — проверять `Get-CimInstance Win32_Process -Filter "Name='python.exe'"`
  и не плодить второй экземпляр (Telegram отдаёт TelegramConflictError и рвёт polling
  случайным образом между инстансами — вероятная причина части старой путаницы со статистикой).
  При обновлении кода: остановить пользовательский процесс, запустить новый с тем же кодом.
