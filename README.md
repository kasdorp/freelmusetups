# 🏁 LMU Setup Bot — Telegram-бот сетапов для Le Mans Ultimate

Бот бесплатно выдаёт сетапы (.svm) для LMU. Пользователь выбирает:
**Класс → Машина → Трасса → Автор сетапа** — и получает файл с инструкцией по установке.
Интерфейс на русском и английском (выбор при /start).

---

## 🚀 Первый запуск (5 минут)

### 1. Создайте бота в Telegram
1. Откройте в Telegram бота **@BotFather**
2. Отправьте команду `/newbot`
3. Придумайте имя (например `LMU Free Setups`) и username (например `lmu_freesetups_bot`)
4. BotFather пришлёт **токен** вида `1234567890:AAEhBOweik6ad9r_QXMENQjcrGbqCr5yTOs` — скопируйте его

### 2. Настройте бота
1. Скопируйте файл `.env.example` → переименуйте копию в `.env`
2. Откройте `.env` блокнотом и вставьте токен: `BOT_TOKEN=ваш_токен`

### 3. Запустите
- **Windows**: двойной клик по **`start_bot.bat`** — при первом запуске он сам установит всё нужное.
- **Linux/macOS**: `chmod +x start_bot.sh && ./start_bot.sh` (нужен `python3` и `python3-venv`).

Бот работает, пока открыт этот процесс (и включена машина). Для круглосуточной работы
на Linux-сервере см. раздел про systemd ниже.

### 4. Станьте админом (по желанию)
1. Напишите своему боту команду `/id` — он пришлёт ваш Telegram ID
2. Впишите его в `.env`: `ADMIN_IDS=ваш_id` (несколько — через запятую: `ADMIN_IDS=id1,id2`)
3. Перезапустите бота. Теперь доступны админ-команды:
   - `/stats` — статистика (пользователи, скачивания)
   - `/reload` — перечитать папку сетапов немедленно
   - `/setversion 1.3.4` — сменить версию игры, показываемую в меню (без аргумента — показать текущую)
   - `/update` — сделать `git pull` в папке бота и перезапуститься на свежем коде
     (нужно, чтобы бот был запущен из git-репозитория, см. раздел «Обновление через git» ниже)
   - `/newsetups` — разослать всем пользователям бота уведомление о новых сетапах,
     добавленных с прошлого раза (сравнивает библиотеку с сохранённым «снимком»).
     При самом первом запуске команды ничего не рассылает — просто запоминает
     текущую библиотеку как точку отсчёта (иначе разослало бы всем сразу всю библиотеку)
   - `/admins` — список текущих админов
   - `/addadmin 123456789` — добавить админа по его Telegram ID (не трогая `.env`, без перезапуска)
   - `/removeadmin 123456789` — убрать админа, добавленного через `/addadmin`
     (админов из `.env` так убрать нельзя — это страховка от случайной потери доступа)

## 📦 Как добавлять / обновлять сетапы

**Просто киньте `.svm` файл в папку `setups\<Трасса>\`** — и всё. Через ~15 секунд
он появится в боте. Перезапуск не нужен, код менять не нужно.

- Имена папок трасс — такие же, как у игры в `UserData\player\Settings\`
  (Lemans, Imola, Spa, Interlagos, Monza, Bahrain, Fuji, Qatar, Sebring, ...).
  Нет нужной папки — создайте с таким же именем.
- **Машину бот определяет сам** из содержимого файла — ошибиться невозможно.
- **Автор** определяется по первому слову имени файла (`HYMO 1.3.3 RCF LM ER.svm` → HYMO).
  Либо кладите файлы в подпапку автора: `setups\Imola\HYMO\файл.svm` — тогда
  автор = имя подпапки (надёжнее для файлов со «странными» именами).
- Обновление версии: закиньте новый файл, старый при желании удалите.
- **Спрятать файл от бота**: добавьте `_` в начало имени файла или папки
  (например `_мой кастом.svm` или папка `setups\Imola\_тесты\`) — бот его не увидит.

### Откуда взялись цифры Q / R в боте
- ⏱ = квалификационный сетап (в имени файла есть `Q`, `EQ`, `Quali`...)
- 🏁 = гоночный (в имени `R`, `ER`, `Race`...)

## 🗂 Структура проекта

| Файл | Назначение |
|---|---|
| `bot.py` | Точка входа |
| `handlers.py` | Логика меню и выдачи файлов |
| `keyboards.py` | Кнопки |
| `library.py` | Сканер папки `setups/` (авто-обновление) |

| `i18n.py` | Все тексты EN/RU |
| `storage.py` | Язык пользователей + счётчики скачиваний (`data/`) |

| `deploy/freelmusetups.service` | Шаблон systemd-юнита для автозапуска на Linux |
| `schedule.py` | «Что сейчас в игре» — расписание Daily/Weekly/Special с lmuschedule.com |

## 📅 «Что сейчас в игре»
Кнопка в главном меню показывает активные на этой неделе комбинации
класс/трасса для Daily Races (Beginner/Intermediate/Advanced), плюс текущие
Weekly Race и Special Event. Данные берутся с lmuschedule.com (неофициально,
через их внутренний API) и кэшируются на 10 минут. Показывает только
**текущую** неделю — у источника нет данных наперёд для этого раздела.
Если сайт изменит свой API — бот не упадёт, просто покажет сообщение
«не удалось загрузить расписание».

## 🔮 Будущие апдейты игры
Новые машины/трассы из DLC бота **не ломают**: неизвестная машина покажется в классе
"Other", неизвестная трасса — по имени папки. Чтобы отображалось красиво, достаточно
добавить одну строку в `catalog.py` (словари `CARS` / `TRACKS`).

## 💡 Чтобы бот работал 24/7
Код не привязан к Windows (long polling, чистый Python) — можно разместить на VPS
(Linux или Windows) или сервисах типа Railway/PythonAnywhere.

### Обновление через git
Проект хранится в git-репозитории. Рабочий цикл:
1. У себя добавляете сетапы / меняете код → `git add` → `git commit` → `git push`
2. На сервере пишете боту `/update` — он сам сделает `git pull` и перезапустится

Так одной командой в Telegram обновляются и код, и вся библиотека сетапов —
без захода на сервер по RDP/SSH.

### Автозапуск на Linux (systemd)
Файл `deploy/freelmusetups.service` — шаблон systemd-юнита. Поправьте в нём
`User=` и `WorkingDirectory=` под свой сервер, затем:
```
sudo cp deploy/freelmusetups.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now freelmusetups
```
Бот будет сам подниматься после перезагрузки сервера и перезапускаться при сбое.

⚠️ Одновременно должна работать только **одна** копия бота (один токен — одна
активная сессия polling), иначе Telegram будет рвать соединение обеим ошибкой
`TelegramConflictError`. Переезжая на сервер — останавливайте локальный запуск.
